# Limen

Identity-aware access to your infrastructure. Short-lived, audited, self-hosted.

Engineers log in through their identity provider and get short-lived, audited access to SSH hosts, databases, Kubernetes, message brokers and internal apps. No static keys or shared passwords, and an audit trail you can verify yourself.

| Repository | What it is |
|---|---|
| [limen](https://github.com/limen-dev/limen) | The control plane, proxy, worker, CLI and docs |
| [terraform-provider-limen](https://github.com/limen-dev/terraform-provider-limen) | Terraform and OpenTofu provider for the Limen management API |
| [homebrew-tap](https://github.com/limen-dev/homebrew-tap) | `brew install limen-dev/tap/limen` |
