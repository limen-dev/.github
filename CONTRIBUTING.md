# Contributing

Thanks for helping with Limen. Each repository in `limen-dev` can have its own `CONTRIBUTING.md`; this one applies where it doesn't.

- **Security problems:** report them privately, never as an issue. See [SECURITY.md](SECURITY.md).
- **Where to open an issue:** in the repository the change belongs to. Anything about the control plane, proxy, worker or CLI goes to [limen-dev/limen](https://github.com/limen-dev/limen).
- **Pull requests:** open them as drafts, and keep them small and focused. Describe what you ran to verify the change; label anything tested only against a stand-in as `unverified`.
- **Commits:** [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `chore:`...).

The full guide, with the project's rules and how to run the tests, is in [limen-dev/limen's CONTRIBUTING.md](https://github.com/limen-dev/limen/blob/main/CONTRIBUTING.md).
