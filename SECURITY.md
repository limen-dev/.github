# Security policy

Please don't open a public issue, pull request or discussion for a security problem.

Report it through GitHub's private vulnerability reporting on the affected repository: its **Security** tab, then **Report a vulnerability**. If you're not sure which repository is affected, use [limen-dev/limen](https://github.com/limen-dev/limen/security/advisories/new).

What we want to hear about, what is out of scope and what happens next are in [the Limen security policy](https://github.com/limen-dev/limen/blob/main/SECURITY.md).
