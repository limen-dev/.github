# limen-dev/.github

Organization-wide defaults for the `limen-dev` repositories.

- `profile/README.md`: the organization's profile page on GitHub.
- `SECURITY.md`, `CONTRIBUTING.md`, `ISSUE_TEMPLATE/` and `PULL_REQUEST_TEMPLATE.md`: defaults for repositories that don't have their own. `limen-dev/limen` has its own; these cover the provider and the tap.

GitHub uses the profile README and the default community health files only while this repository is public. It stays private until `limen-dev/limen` goes public.
